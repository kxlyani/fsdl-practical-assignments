# Assignment 07 – Saveur Atlas: Travel & Food Discovery Platform

**Subject:** Full Stack Development Lab (FSDL)

## Overview

Saveur Atlas is a full-stack MERN application that allows users to explore travel destinations, discover regional dishes, view restaurants, read travel articles, bookmark favourites, and post reviews.

The project consists of two parts:

- **nomad-bite** – Backend REST API built with Express and MongoDB
- **traw** – Frontend built with React and Vite

---

## Features

- User Registration & Login (JWT Authentication)
- Browse Destinations, Dishes, and Restaurants
- Read Travel Articles
- Add Reviews and Bookmarks
- Responsive React Frontend
- RESTful Backend API

---

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios

### Backend
