# MARKET — Vanilla JS E-Commerce Site

A front-end fashion e-commerce site built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools — just plain DOM manipulation and CSS.

## Features

- Home, Collection, and Campaign pages with a single-page navigation flow
- Product grid with category filtering (Women / Men / Accessories)
- Slide-out cart drawer with live item count
- Multi-step checkout: shipping details → payment (Card / UPI / COD) → order review → confirmation
- Card number and expiry auto-formatting
- Scroll-reveal animations on section content

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no libraries or frameworks)

## Files

```
index.html   → Page structure and markup
style.css    → Styling and layout
main.js      → Navigation, cart logic, filtering, and checkout flow
```

## Running Locally

Just open `index.html` in a browser — no build step or server required.
